#### features (id prefix FEAT)
One capability the system provides that a user or actor can perceive.
- Example: "會員可取消訂單".
- Describes WHAT the system can do. Conditions and limits on that capability belong in businessRules.
- `actorIds`: ACT ids of actors involved. `inputs` / `outputs`: data or triggers stated in the documents.
- `dependsOn`: FEAT ids of other features, or DEP ids of external dependencies, this feature needs. Dependencies on external systems themselves are recorded in the dependencies section.
